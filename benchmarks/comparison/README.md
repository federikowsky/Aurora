# Historical comparison fixtures

This directory retains competitor fixtures for investigation; the linked historical prose contains earlier result claims. They are **historical evidence, not a current comparative claim or approved architecture**. The current procedure is in [the benchmark guide](../README.md).

Before rerunning `run_comparison.sh`, inspect actual toolchain/dependency pins, server semantics, worker counts, safety settings, payloads, middleware and client placement. Reproduce all candidates with equivalent useful behavior; do not infer causality or rank from unmatched configurations. External projects are sources of technical evidence, not architectural templates for Aurora.

The previous report and invocation assumptions remain available in [the pinned original](https://github.com/federikowsky/Aurora/blob/3416660672229179b947e54bf4bfb650309aa38e/benchmarks/comparison/README.md). Files in this directory are not part of ordinary CI and have not been recertified by the documentation re-baseline.
